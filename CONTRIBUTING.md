# Contribuindo

Obrigado por contribuir!

## Como contribuir
1. Faça um fork do repositório
2. Crie uma branch:
   - `feat/minha-mudanca`
   - `fix/ajuste-x`
3. Faça commits pequenos e descritivos
4. Abra um Pull Request explicando:
   - o problema
   - a solução
   - como testar

## Padrões
- Documentação em Markdown
- Comandos em blocos `bash`
- Evitar segredos no repositório (não enviar `.env`, tokens, credenciais)
